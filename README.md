# 🔐 Caesar Cipher – Python

## 📌 About the Project
A simple Caesar Cipher encryption and decryption program built using Python.

This project is part of my **100 Days of Python Challenge – Day 8**.

## 🚀 Features
- Encrypt and decrypt messages
- Support custom shift numbers
- Preserve spaces and special characters
- Encrypt or decrypt multiple messages in one session

## 🛠️ Technologies Used
- Python 3

## 💻 How to Run
1. Download the project.
2. Open a terminal in the project folder.
3. Run `python main.py`.
4. Follow the instructions displayed in the terminal.
